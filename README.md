# Бот для сбора лотов по банкротству (авто) + оценка Avito

## Установка
```
pip install -r requirements.txt
```

## Настройка
1. Скопируйте `local_secrets.example.py` в `local_secrets.py` и впишите туда
   `SPREADSHEET_ID` (ID вашей Google Таблицы из URL), ключ TRONK и токен бота.
2. Положите скачанный `service_account.json` рядом со скриптами (или укажите
   другой путь в `config.SERVICE_ACCOUNT_FILE`).
3. Дайте service account'у доступ "Редактор" к таблице (email вида
   `xxx@yyy.iam.gserviceaccount.com`, см. вкладку Details в Google Cloud Console).
4. При желании поправьте `SEARCH_PARAMS` в `config.py` под свой регион/категорию.
5. Скопируйте `local_secrets.example.py` в `local_secrets.py` и впишите ключ TRONK
   и токен Telegram-бота. Этот файл (как и `service_account.json`) в git не хранится.

## Проверка подключения к таблице
```
python sheets_writer.py
```
Если выведет "Подключение успешно" - всё настроено верно.

## Запуск
```
python main.py
```
Бот пройдёт до `config.MAX_PAGES` страниц поиска, для каждого нового лота
(которого ещё нет в таблице) откроет карточку, вытащит данные, при наличии
VIN и пробега запросит оценку на Авито и запишет строку в таблицу.

## Повторные запуски
Скрипт можно запускать регулярно (например, через cron / планировщик задач) -
уже занесённые лоты (по `lot_id`) не дублируются и повторно не парсятся.

## Известные ограничения (см. также комментарии в файлах)
- `avito_valuation.py`: город для оценки захардкожен как Москва (см. `DEFAULT_LOCATION`);
  антибот-защита Qrator может потребовать пауз/ротации прокси при активном использовании.
- Сайт торгов явно запрещает автоматический доступ в своём robots.txt - учитывайте
  это при выборе частоты запусков.
- Пробег на сайте торгов не всегда публикуется отдельным полем - иногда его просто
  нет в тексте лота, тогда оценка Avito для этого лота пропускается.
