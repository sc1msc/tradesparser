# HonestLot: машины с торгов по банкротству

Сбор лотов с торгов по банкротству (легковые машины, Москва и Московская область), оценка по
Авто.ру, подборки в Telegram-канал и мини-приложение Telegram [@honestlot_bot](https://t.me/honestlot_bot).

Как всё устроено, что видит пользователь и что делать при сбоях — в **[вики проекта](wiki/README.md)**.
Как обновляются данные — [DATA_UPDATES.md](DATA_UPDATES.md). Мини-приложение — [miniapp/README.md](miniapp/README.md).

## Установка
```
pip install -r requirements.txt
playwright install chromium
```

## Настройка
1. Скопируйте `local_secrets.example.py` в `local_secrets.py` и впишите туда
   `SPREADSHEET_ID` (ID Google Таблицы из URL), ключ TRONK, токен Telegram-бота и остальное по
   комментариям в шаблоне. Этот файл (как и `service_account.json`) в git не хранится.
2. Положите скачанный `service_account.json` рядом со скриптами (или укажите
   другой путь в `config.SERVICE_ACCOUNT_FILE`).
3. Дайте service account'у доступ "Редактор" к таблице (email вида
   `xxx@yyy.iam.gserviceaccount.com`, см. вкладку Details в Google Cloud Console).
4. При желании поправьте `SEARCH_PARAMS` в `config.py` под свой регион/категорию.

## Проверка подключения к таблице
```
python sheets_writer.py
```
Если выведет "Подключение успешно" - всё настроено верно.

## Запуск
```
python run_pipeline.py          # весь конвейер: сбор, пробег, пересборки, Авто.ру, подборки, выгрузка в мини-апп
python run_pipeline.py --auto   # то же без вопросов, с логом и уведомлениями (так работает ежедневный автозапуск)
python send_digest.py           # публикация подборки в канал (вручную)
```
Каждый шаг можно запустить и отдельно (`python main.py` и т.д.) - см. [вики: конвейер данных](wiki/pipeline.md).
Уже занесённые лоты (по `lot_id`) не дублируются и повторно не парсятся.

## Известные ограничения
- Сайт торгов явно запрещает автоматический доступ в своём robots.txt - не уменьшайте паузы
  между запросами и не запускайте сбор слишком часто.
- Авто.ру может показать капчу: оценка идёт в видимом окне браузера, капчу решает человек.
- Остальное - в [вики: ограничения и планы](wiki/roadmap.md).
