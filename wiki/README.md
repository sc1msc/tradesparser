# Вики HonestLot

Справочник по проекту HonestLot. Главный читатель — агент поддержки: он отвечает пользователям
мини-приложения и канала и передаёт владельцу то, что сам решить не может. Вики пригодится и
человеку, который разбирается в проекте впервые.

Вики написана по коду и документам репозитория и актуальна на **11.10.2026**. Если вики и код
расходятся, прав код. Как поддерживать вики в актуальном виде — в конце страницы.

## Коротко о проекте

HonestLot — сервис-подборка машин с торгов по банкротству в Москве и Московской области.
Каждое утро программа на компьютере владельца собирает новые лоты с сайта-агрегатора
[торги-россии.рф](https://xn----etbpba5admdlad.xn--p1ai), оценивает каждую машину по Авто.ру и
выкладывает лоты в мини-приложение Telegram. Пользователь видит цену лота рядом с рыночной
оценкой, срок подачи заявки, график снижения цены и может сохранить лот в избранное.

HonestLot не организует торги, не продаёт машины и не участвует в торгах за пользователя.
Пользоваться приложением сейчас бесплатно.

## Как подключить агента поддержки

- Инструкция агенту — [Правила поддержки](support-playbook.md). База знаний — страницы раздела
  «Продукт» и эта главная.
- Агенту, который отвечает пользователям напрямую, лучше **не давать** страницы раздела «Как
  устроено»: там адреса серверов, команды и места хранения секретов. Пользователь может
  попытаться выведать их у агента. Для эскалаций хватит раздела «Симптомы у пользователей» из
  [Уведомлений и сбоев](runbook.md#симптомы-у-пользователей--диагностика) — его можно дать
  отдельно.
- Агенту-помощнику владельца (разбор сбоев, доработки) нужна вся вики и доступ к репозиторию.

## Шпаргалка: ключевые факты

- **Что в приложении:** торги по банкротству, раздел «Легковой транспорт», Москва и Московская
  область. Права требования и доли в машине не показываем.
- **Окно:** лоты, у которых приём заявок заканчивается в ближайшие 30 дней. У публичного
  предложения считается срок текущего этапа.
- **Обновление:** раз в сутки, утром (автозапуск в 07:00 по Москве, данные доходят до приложения
  обычно к 8–9 часам). Цена и срок публичного предложения пересчитываются по графику в момент
  открытия приложения.
- **Рыночная цена:** оценка Авто.ру — вилка «от и до». Процент к рынку считается от середины
  вилки.
- **«Оценка может быть неточной»:** Авто.ру сам указал погрешность 90% и больше или не смог
  однозначно определить машину.
- **Пробег с «~»:** оценка по году выпуска, 16 600 км в год.
- **«Скрыть битые»** включена по умолчанию: прячет сгоревшие, разобранные, «на запчасти» — по
  тексту лота и по проверке фото части самых дешёвых лотов.
- **Избранное следует за машиной** (по VIN): если машину выставят снова, новый лот появится в
  избранном. Закрытые торги уходят в архив через 60 дней.
- **Время** везде московское.
- **Telegram:** мини-приложение — бот [@honestlot_bot](https://t.me/honestlot_bot), канал
  [@honestlot](https://t.me/honestlot), поддержка — [@honestlot_support_bot](https://t.me/honestlot_support_bot).

## Как поддерживать вики

- Источник истины — код. В каждом модуле есть длинный докстринг: почему сделано именно так.
- Поменяли поведение — поправьте страницу. Что где описано:

| Изменили | Поправить страницы |
|---|---|
| `miniapp/frontend/app.js` (надписи, экраны, фильтры) | miniapp-guide, faq |
| `miniapp/backend/app/lots.py` (видимость, сортировка, избранное) | numbers, miniapp-guide, miniapp-internals |
| `lot_metrics.py` (процент, «битые», тип лота, VIN, госномер) | numbers, glossary |
| `bidding_schedule.py` (цена и срок публичного предложения) | numbers |
| шаги `run_pipeline.py`, `config.py` | pipeline, config, runbook |
| новые `automation.alert(...)` | runbook |
| серверы, домены, боты | infrastructure, architecture |
| `TODO.md` (сделано или добавлено) | roadmap |
| `miniapp/backend/app/billing.py`, `pay_providers.py`, `frontend/pay/`, `site.py` + `site_pages/` (подписка, оплата, страницы сайта) | payments, monetization |

- Значения настроек на странице [Настройки](config.md) переписаны из `config.py` на 11.10.2026.
  Перед ответом, где важна точная цифра, сверьтесь с кодом.
