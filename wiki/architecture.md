# Как устроено

## Компоненты

```
                     ┌────────────────────── ПК владельца (Windows) ─────────────────────┐
торги-россии.рф ───► │ run_pipeline.py --auto  (Планировщик, каждый день 07:00 МСК)      │
(агрегатор торгов)   │   1 сбор лотов ─ 2 пробег TRONK ─ 3,4 пересборки ─ 5 оценка Авто.ру │
TRONK (платно) ────► │   ─ 6 подборки ─ 7 выгрузка в мини-апп                              │
Авто.ру (браузер) ─► │ send_digest.py (вручную) ──────────────────────────► канал @honestlot│
                     │ уведомления о сбоях ────────────────────────► владельцу в Telegram │
                     └──────┬──────────────────────────────────────────────┬───────────┘
                            │ чтение/запись                                │ POST /api/import
                            ▼                                              ▼
                  Google-таблица (одна)            ВМ Yandex Cloud, honestlot.ru (Docker)
                  lots → lots_processed →           caddy (HTTPS) → api (FastAPI + SQLite + фронтенд)
                  lots_current_month → подборки,                  → bot @honestlot_bot
                  vin_cache                                         │
                                                                    ▼ через релей
                                                  VPS в Амстердаме, tg.honestlot.ru → api.telegram.org
```

| Компонент | Где | Что делает |
|---|---|---|
| Конвейер данных | ПК владельца, папка репозитория | собирает лоты, обогащает, пересобирает листы, выгружает в мини-апп. См. [Конвейер данных](pipeline.md) |
| Google-таблица | Google Drive, доступ через service account | единственное общее хранилище конвейера: каждый шаг читает и пишет листы. См. [Google-таблица](google-sheet.md) |
| Сервер мини-аппа | ВМ в Yandex Cloud, `honestlot.ru` | API, база SQLite (пользователи, избранное, лоты), фронтенд, бот. См. [Мини-приложение изнутри](miniapp-internals.md) |
| Релей Telegram | VPS в Амстердаме, `tg.honestlot.ru` | пересылает запросы ВМ в Telegram Bot API: из российской сети провайдер блокирует Telegram |
| Канал @honestlot | Telegram | посты-подборки, публикуются вручную с ПК (`send_digest.py`) |
| Бот поддержки @honestlot_support_bot | Telegram | вне репозитория, сюда ведёт кнопка «Написать в поддержку» |

Подробнее о хостах и доступах — [Серверы и доступы](infrastructure.md).

## Почему так

- **Конвейер на ПК, а не на сервере.** С ВМ в Yandex Cloud Авто.ру сразу показывает капчу, а
  Claude API и Telegram недоступны (проверено 06.10.2026). На ПК капчу может решить человек: браузер
  открыт в видимом окне.
- **Google-таблица как хранилище.** Исторически: скрипты появлялись по одному, таблицу удобно
  смотреть и править руками. Шаги связаны только через листы, каждый шаг можно запустить
  отдельно.
- **SQLite на сервере.** Лотов сотни (до тысяч), запись — одна выгрузка в сутки и клики «в
  избранное». Бэкап — копия файла.
- **Релей.** Провайдер ВМ блокирует api.telegram.org в обе стороны, вебхук тоже не доходит.
  Релей на зарубежном VPS — только Caddy, без данных пользователей (152-ФЗ: данные россиян
  хранятся в России).
- **Общий код расчётов.** `lot_metrics.py` (процент к рынку, «битые», тип лота) и
  `bidding_schedule.py` (цена и срок публичного предложения) — одни на конвейер, канал и
  мини-апп: модули копируются в Docker-образ. Формулы не дублировать.

## Сутки из жизни данных

| Время (МСК) | Что происходит |
|---|---|
| ~04:00–04:20 | агрегатор обновляет лоты ночной пачкой |
| 04:00+ | сервер мини-аппа делает ежедневную копию базы |
| 07:00 | Планировщик Windows запускает `run_pipeline_auto.bat` → `run_pipeline.py --auto` |
| 06:00, 14:00, 20:00 | сервер мини-аппа собирает новые лоты прямо с площадок (ТоргГрупп, МЭТС, ЦДТ, Lot-online, `etp_collect.py`) |
| 05:00, 11:00, 16:00, 21:00 | сервер мини-аппа проверяет статус публичных предложений и лотов избранного на агрегаторе и на самих ЭТП (`status_refresh.py`); закрытые торги уходят из ленты сразу |
| 07:00–07:30 | шаг 1: новые лоты с сайта агрегатора и с сервера (собранные с площадок), статусы с сервера в лист, перепроверка того, что сервер не проверил |
| далее | шаг 2: пробег TRONK для новых VIN; шаги 3–4: пересборка листов |
| далее | шаг 5: оценка новых лотов на Авто.ру в окне браузера (~10–12 секунд на лот) |
| далее | шаг 6: подборки; шаг 7: ДТП по VIN новых машин (TRONK); шаг 8: карточки лотов → выгрузка в мини-апп → итоги избранного → копия базы на ПК |
| ~07:30–09:00 | мини-апп показывает свежие данные. Если были проблемы — одно сообщение владельцу |
| весь день | мини-апп пересчитывает цену и срок публичных предложений по графику при каждом запросе |
| раз в час | сторож на сервере проверяет, была ли выгрузка за 36 часов |
| когда решит владелец | `send_digest.py` публикует подборку в канал |

Прогоны 07–10.10.2026 длились от 23 минут до 2 часов.
